# Security policy

Notes runs code on the machine that runs Orca: a Node worker with your user account's access. Please report anything that lets it do more than the README says.

## Reporting a vulnerability

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/eliasjnior/orca-worktree-notes/security/advisories/new),
not in a public issue. Include the version, what an attacker controls (for example a crafted
note) and what it leads to.

You should get an answer within a week. Fixes ship as a new version, which Orca offers as an
update.

## Supported versions

Only the newest tagged version gets security fixes.
